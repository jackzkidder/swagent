One-time setup

Connect your Anthropic account

SwAgent runs on your own Anthropic API key. You pay Anthropic directly for what you use; there is no SwAgent subscription.

  1. Sign in to the Anthropic Console and create an API key. Name it SwAgent so you can recognise it later.
  2. Make sure the account has credit. API usage is prepaid. A simple part usually costs well under a dollar.
  3. Paste the key below. It starts with sk-ant-.

What leaves this PC

Everything goes to Anthropic (api.anthropic.com) and nowhere else: your messages, measurements and viewport images of the model, and the file paths of anything you ask SwAgent to save or export.

  • Your key is stored encrypted under your Windows account and is sent only to Anthropic.
  • File lists from batch changes stay on this PC; the model sees row numbers.
  • There is no SwAgent server and no analytics.
